### Byte-parity hardening found a real asymmetry

Adding the length assertion to `assert_byte_identical` (it iterated
`min(len, len)` and never compared lengths) immediately failed: corridor
histories were **320 native vs 322 jupedsim**. Cause is benign but was
invisible -- JuPedSim runs 2 more bookkeeping iterations after the last
retirement (its exit-stage lag), appending empty snapshots. The jps loop now
stops where the native loop stops, on the step that retires the last agent.
Also added: the corridor test asserts all 3 agents exited (1-of-3 used to
pass), and the corner test asserts 300 full steps with the full roster so
"byte-identical" cannot mean "identically truncated".

### Dynamics safety net

`resolve_dynamics` now warns whenever a **metadata-capable** policy falls back
to `_DYNAMICS_DEFAULTS`. A v1 artefact used to self-configure its obs/action
blocks silently and then run w=0.05 / clamp 5.0 against the trained 0.8 / 3.0
of every current best run -- a ~16x change in the velocity-response time
constant with no warning naming dynamics anywhere. `ConstantPolicy` stays
silent through the existing `metadata_capable` flag. The mismatch tolerance is
now relative (an absolute 1e-12 is sub-ULP at `ulp(30000.0) = 3.6e-12`, so
adjacent doubles raised as disagreement). The 0.05/5.0 docstrings no longer
call these "the crowdrl default" -- they are the pre-v2 *adapter* constants,
pinned so v1 deployments do not shift when training defaults move.

`validate_dynamics_dict` now checks values instead of coercing them: non-object
JSON payloads (`[]`, `3`, `"x"`) raise a clean ValueError instead of a bare
`AttributeError` from `.items()`, NaN/inf/negatives are rejected, and bools are
rejected (bool is an int subclass, so `float(True) == 1.0` sailed through).
Zero is still accepted -- it legitimately disables contact physics.

`LearnedPolicyModel` gained lockstep's dt guard (warns once, not per agent per
step).
